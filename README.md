# KreditKiller
# 🤖 Кредитный Планировщик

Telegram-бот для учета кредитов и планирования бюджета.

## 📋 Возможности

- ✅ Добавление кредитов с графиком платежей
- ✅ Учет доходов (зарплата)
- ✅ Прогноз платежей с учетом зарплаты
- ✅ Оптимизация бюджета
- ✅ Статистика и история
- ✅ Ближайшие платежи

## 🚀 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/add` | Добавить кредит |
| `/list` | Список кредитов |
| `/pay` | Внести платеж |
| `/next` | Ближайшие платежи |
| `/forecast` | Прогноз с зарплатой |
| `/salary` | Настроить зарплату |
| `/my_salary` | Мои доходы |
| `/dashboard` | Статистика |
| `/optimize` | Оптимизация платежей |
| `/history` | История платежей |
| `/close_credit` | Закрыть кредит |
| `/help` | Помощь |
